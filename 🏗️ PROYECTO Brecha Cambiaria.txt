🏗️ PROYECTO: HierroEnLinea (SaaS de Blindaje Financiero)1. PROPÓSITO DEL SISTEMAPlataforma predictiva para PyMEs en Venezuela que resuelve el riesgo de descapitalización por brecha cambiaria. Calcula precios de reposición y cuotas de financiamiento (Modelo Cashea) proyectando el valor del Bolívar a 14, 28 y 42 días mediante regresión lineal.2. ARQUITECTURA TÉCNICA (STACK)Backend: Django 6.0 / Python 3.13.Base de Datos: SQLite (Modelos: DailyRate para tasas y Product para inventario).Motor de Inteligencia: NumPy (Cálculo de Mínimos Cuadrados para línea de tendencia \(y = mx + b\)).Frontend: HTML5/CSS3 (Bypass de CDNs para funcionamiento offline/CANTV) + JavaScript puro para simulador dinámico.3. LÓGICA DE NEGOCIO (EL "VENENO" MATEMÁTICO)Factor G15: Es el valor medio proyectado del GAP (Binance/BCV - 1) en un horizonte de 131 días (91 históricos + 42 futuros).Triangulación de Precios:Contado BCV: (Costo USD * Tasa Binance Hoy) / Tasa BCV Hoy.Precio Cashea: (Base Cashea * Binance Proyectado / BCV Proyectado) * Factor G15.Inicial Cashea: (Precio Cashea * 0.5) * 1.018 (Incluye 1.8% IGTF).Cuotas: 50% restante dividido en 3 partes iguales.4. ESTADO ACTUAL DEL PROYECTOAutenticación: Sistema de Registro y Login operativo con acceso restringido al Dashboard.Dashboard: Simulador de escenarios dinámico funcional con visualización de histórico de 15 días.Inventario: Carga masiva mediante script ejecutar_carga.py validada (20 productos cargados).Lista de Precios: Vista /precios/ operativa con 4 columnas de precios (Contado Cash, Contado BCV, Cashea Full, Cashea Dcto).5. PENDIENTES PARA EL PRÓXIMO SPRINTMódulo PDF: Implementación de exportación de lista de precios a PDF.Gráficas: Rehabilitar Chart.js localmente para el visual de la brecha.Monetización: Lógica de suscripción para funciones Pro (Carga de CSV y PDF).
